# IDAX Ledger documentation

Documentación de discovery, arquitectura, desarrollo, seguridad y operación de
la red XRPL privada. El código queda deliberadamente separado en repositorios
independientes.

La Fase 6 añade la integración nativa con el shell IDAX, el explorer de la red
privada y el flujo completo de creación y verificación de Proofs. Consulte
`DEVELOPMENT.md` para rutas, validaciones y evidencia E2E.
