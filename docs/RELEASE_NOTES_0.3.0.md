# IDAX Ledger 0.3.0 release notes

IDAX Ledger 0.3.0 adopts IDAX Core Runtime 0.3.0 and participates in the
complete public local stack provided by IDAX Shell 0.3.0.

The release includes the integrated public frontend extension, authenticated
module routing, local Docker Compose support and the existing tenant-aware XRPL
proof model. No proof canonicalization or anchor format is changed.

Upgrade Core and Shell to 0.3.0 before deploying this module release.
