# Third-party dependency and license review

Reproducible inventories are the CycloneDX SBOMs generated by the backend and
frontend build commands. Primary direct components reviewed for 0.1.0:

| Component | License | Assessment |
|---|---|---|
| Spring Boot / Spring Framework | Apache-2.0 | compatible |
| PostgreSQL JDBC | BSD-2-Clause | compatible |
| Flyway Community | Apache-2.0 | compatible |
| xrpl4j | Apache-2.0 | compatible |
| JSON Canonicalization (erdtman) | Apache-2.0 | compatible |
| React / React DOM | MIT | compatible |
| esbuild | MIT | compatible |
| PostgreSQL container | PostgreSQL License | compatible |
| `xrpllabsofficial/xrpld:3.3.0` / rippled | ISC | compatible |

No direct GPL, AGPL or strong-copyleft dependency was identified. Transitive
components with missing/ambiguous SBOM license metadata must be reviewed before
redistributing a binary; the SBOM is authoritative over this summary. IDAX core
is an internal build dependency and must be distributed under its own approved
terms. This is an engineering review, not legal advice.
